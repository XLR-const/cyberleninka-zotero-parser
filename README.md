# CyberLeninka-Zotero Deep Parser

Автоматизированный инструмент для глубокого сбора метаданных научных статей с сайта КиберЛенинка и экспорта библиографии в формат **RIS** для последующего анализа в **Zotero** и генерации **CSV** таблиц.

Проект создан в рамках дисциплины «Современные цифровые инструменты научного исследования».

## 🚀 Особенности инструмента (Пайплайн)
1. **Автоматический обход:** Эмуляция реального браузера (Selenium) с поддержкой умного автоматического перелистывания страниц (`page=N`).
2. **Глубокий парсинг (Deep Scraping):** Скрипт заходит на страницу каждой статьи, выковыривая данные, скрытые от общих поисковых роботов.
3. **Регулярные выражения (Regex):** Если издательство не заполнило HTML-теги, регулярки сканируют сырой текст на наличие цифровых идентификаторов **DOI** (`10.XXXX/...`) и кодов **EDN** (eLibrary).
4. **Zotero Ready:** На выходе генерируется библиографический файл `.ris` в кодировке `utf-8-sig` с жесткими переносами строк, который Zotero импортирует за 1 секунду.

## 🛠️ Системные требования и зависимости
Для работы скрипта необходим **Python 3.8+** и следующие библиотеки:
```bash
pip install selenium beautifulsoup4 requests webdriver-manager
```

## 📦 Инструкция по запуску и использованию

### Шаг 1. Сбор данных
1. Запустите основной файл парсера:
   ```bash
   python parser.py
   ```
2. В открывшемся управляемом окне браузера Chrome введите поисковый запрос (например: `"прогнозирование кассовых сборов" "машинное обучение"`) и нажмите кнопку поиска на сайте.
3. Вернитесь в консоль и нажмите `ENTER`. Скрипт самостоятельно соберет 100 статей, автоматически перелистывая страницы, и запишет данные в файл `articles_for_zotero.ris`.

### Шаг 2. Импорт в Zotero и выгрузка CSV
1. Откройте **Zotero**.
2. Перейдите в меню `Файл` -> `Импорт` -> Выберите `Файл (BibTeX, RIS, Zotero RDF...)`.
3. Укажите сгенерированный файл `articles_for_zotero.ris`. Все 100 статей мгновенно появятся в вашей библиотеке с заполненными названиями журналов, аннотациями, ISSN и DOI.
4. Выделите все элементы (`Ctrl + A`), нажмите правой кнопкой мыши -> `Экспортировать элементы...` -> Выберите формат **CSV**.

## 📊 Результаты работы
Итоговый CSV-файл содержит структурированную базу из 100 научных публикаций со следующими заполненными полями: `Title`, `Author`, `Publication Title` (Журнал), `ISSN`, `DOI`, `Url`, а также встроенные коды `[EDN]` в начале поля `Abstract Note` (Аннотация).
